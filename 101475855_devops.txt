DevOps and Software Development

In COMP3104, we learn about DevOps practices and how they support software development.

DevOps focuses on collaboration, automation, and continuous improvement throughout the development process.

Using Git and GitHub allows developers to track changes, manage branches, and collaborate on projects.

I believe these tools are important because they help teams organize their work and reduce errors during development.

One of the most useful concepts I have learned in DevOps is the importance of version control. Working with separate branches allows developers to make changes without directly affecting the main project.

Pull requests help teams review changes before merging them. This makes collaboration more organized and reduces the risk of introducing errors.
